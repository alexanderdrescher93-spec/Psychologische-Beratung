MONOLITH-WEBSITE – ERSTE VERSION

1. Öffne index.html per Doppelklick für eine lokale Vorschau.
2. Ersetze in index.html die Platzhalter-E-Mail kontakt@ihre-domain.de.
3. Ergänze Impressum und Datenschutzerklärung vor Veröffentlichung.
4. Kostenlose Veröffentlichung:
   - GitHub Pages
   - Cloudflare Pages
   - Netlify
5. Eine eigene Domain kann anschließend mit dem Hosting verbunden werden.

DATEIEN
- index.html: Hauptseite
- styles.css: Design
- script.js: mobiles Menü und Jahreszahl
- impressum.html: Platzhalter
- datenschutz.html: Platzhalter
