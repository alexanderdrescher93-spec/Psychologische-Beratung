DRESCHER-BERATUNG – VERSION 3

GitHub aktualisieren:
1. ZIP entpacken.
2. Im Repository auf Add file > Upload files klicken.
3. Alle entpackten Dateien hochladen.
4. Bestehende Dateien ersetzen lassen.
5. Unten Commit changes anklicken.
6. Die Datei CNAME nicht löschen; sie enthält drescher-beratung.de.

Wichtig vor Veröffentlichung:
- Impressum vervollständigen.
- Datenschutzerklärung rechtlich prüfen/anpassen.
- Berufsbezeichnung und Qualifikation korrekt angeben.
- Kontakt-E-Mail prüfen.
- Platzhalter im Abschnitt „Über mich“ später durch ein eigenes Familienfoto ersetzen.
